# 🧱 Stack Overflow：程式碼疊磚遊戲

這是一款以程式設計主題為風格的方塊遊戲，玩家需要控制落下的方塊，將它們排列成指定的錯誤模式，並在堆疊達到上限前清除目標圖樣。

遊戲的核心概念是：
- 你需要觀察右側的「目標圖樣」
- 利用左右移動、旋轉和快速下落來擺放方塊
- 當符合目標錯誤圖樣時，清除它並獲得分數
- 若堆疊碰到頂部，遊戲結束

## 🎮 遊戲目標

在這個遊戲中，右側會顯示一個 5x5 的錯誤模式，例如：
- Null Pointer
- Memory Leak
- Off By One
- Race Condition
- Infinite Loop
- Syntax Error
- Type Mismatch

你的任務是將落下的方塊拼出相同的圖案，讓它符合目標模式，之後就能清除並累積分數。

## ⌨️ 操作方式

- 左右方向鍵：移動方塊
- 上方向鍵：旋轉方塊
- 下方向鍵：快速下落
- 空白鍵：直接落到底部
- P：暫停 / 繼續

## 🧠 遊戲規則

1. 方塊會不斷從上方落下。
2. 你需要在底部或其他方塊之間安排位置。
3. 當一段區域和目標圖樣完全相符時，該區域會被清除。
4. 清除成功後會加分，並更新下一個目標圖樣。
5. 若積木堆疊到達上方邊界，遊戲結束。

## ▶️ 如何執行

這是一個純前端的 HTML / CSS / JavaScript 專案，最簡單的方式是直接開啟 `src/index.html`。

如果你想使用本機伺服器，也可以在專案根目錄執行：

```bash
python -m http.server 8000
```

然後在瀏覽器中打開：

```text
http://localhost:8000/src/index.html
```
